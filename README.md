# AI Resume Analyzer

An NLP-powered resume analysis application built using Python and Streamlit.

# Features

- PDF Resume Upload
- Resume Text Extraction
- ATS Score Calculation
- Skill Detection
- Missing Skills Analysis
- Career Role Prediction
- Personalized Suggestions
- Job Description Matching

# Tech Stack

- Python
- Streamlit
- PDFPlumber
- NLP Concepts

# Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
